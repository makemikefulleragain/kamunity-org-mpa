# Compliance Harm Observations

A short, client-side draft briefing tool for anonymised frontline welfare-compliance observations. It complements the more detailed Welfare Compliance Misalignment Mapper. It does not store, send or validate case information, and it does not establish a policy breach or systemic pattern. Human review is required before sharing any output.

The previous generated artifact incorrectly presented an AI-governance slider under this welfare-compliance title and exposed its FactoryK prompt. That version is preserved in Git history.
